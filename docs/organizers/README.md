## 보내는 방법 (Tidyflow)
1. Saved Jobs에서 해당 Organizer를 고객 Job으로 복사(또는 Claude에게 "신규 고객 …" 지시).
2. 고객 Job → Client Request → 받는 사람 확인 → **Send client requests**.
3. 각 요청서는 필수(required) 항목이 없습니다. 자동 완료되지 않도록 일부러 그렇게 했습니다.

## 알아 둘 점
- 1040 섹션 4–5, 사업체 섹션 6은 조건 없이 항상 보입니다. '아니요'면 서류 칸에서 'I don't have this'를 누르도록 안내되어 있습니다. (Tidyflow API 제한)
- 복수 선택이 안 되므로 소득·공제 항목은 각각 따로 질문합니다.
- 990(비영리) Organizer는 아직 없습니다.
